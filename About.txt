whatsapp-ai-bot anedi personal WhatsApp bot. AI chat, Last.fm updates, weather, media downloader, admin dashboard features tho build chesaru.

✨ Features

· AI Chat: Groq vadadam valla Telugu/English lo human-like replies istundi.
· Last.fm Updates: Prati 15 seconds ki Last.fm recent/now-playing track poll chesi WhatsApp update pampistundi.
· `.lfm`: Last.fm lo latest 10 tracks chupistundi.
· Weather: /weather command tho weather report.
· Media Downloader: YouTube / Instagram / X / Twitter nunchi video + audio download.
· Admin Dashboard: Live stats, messages, AI replies, media sent and Last.fm updates.
· Session Persistence: WhatsApp auth data save avutundi, restart ki QR scan avasaram ledu.
· Noise Filter: Baileys/libsignal verbose logs suppress chestundi.

🛠️ Prerequisites (Termux lo)

· Node.js version 20 or higher
· yt-dlp
· ffmpeg
· Last.fm API key and Last.fm username

🚀 Quick Start

1. Repository clone:
   git clone https://github.com/pspktech/whatsapp-ai-bot.git
   cd whatsapp-ai-bot

2. Dependencies install:
   npm install

3. Environment setup:
   cp .env.example .env

   `.env` lo Groq, Last.fm and WhatsApp target settings add cheyyandi.

4. Bot run:
   npm start

5. First run lo QR code ni WhatsApp → Linked Devices → Link a Device tho scan cheyyandi.

🔑 Important .env variables

· PORT=3000
· ADMIN_PASSWORD=change-this-password
· GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxx
· LASTFM_API_KEY=xxxxxxxxxxxxxxxx
· LASTFM_USERNAME=your-lastfm-username
· LASTFM_POLL_INTERVAL=15000
· LASTFM_TARGET_JID=91XXXXXXXXXX@s.whatsapp.net
· WHATSAPP_TARGET_JID=91XXXXXXXXXX@s.whatsapp.net
· WEATHER_CITY=Hyderabad
