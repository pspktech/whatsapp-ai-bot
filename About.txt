whatsapp-ai-bot anedi oka personal WhatsApp bot, idi AI chat, Spotify updates, weather reports, mariyu media downloader features tho untundi. Baileys + Express tho build chesaru.

✨ Features

· AI Chat: Groq (LLaMA / GPT-OSS) vadadam valla Telugu/English lo human-like replies istundi.
· Spotify Now Playing: Prati 10 seconds ki Spotify ni poll chesi, "Ippudu vintunna" updates pampistundi.
· Weather: /weather command tho daily 7 AM ki auto report (Open-Meteo, API key avasaram ledu).
· Media Downloader: YouTube / Instagram / X / Twitter nunchi video + audio ni yt-dlp tho download cheyochu.
· Spotify Downloader: Spotify link paste cheste, YouTube nunchi MP3 download chestundi.
· Admin Dashboard: Live stats (messages, AI replies, media sent, uptime) chupistundi.
· Session Persistence: WhatsApp login data/auth lo save avutundi, restart ki QR scan avasaram ledu.
· Noise Filter: Baileys/libsignal verbose logs ni suppress chestundi.

🛠️ Prerequisites (Termux lo)

Ee bot run cheyadaniki ee tools kavali:

· Node.js (version 18 leda adi kante ekkuva)
· yt-dlp (media downloader)
· ffmpeg (audio conversion)
· Spotify Premium (optional, "now playing" feature kosam)

🚀 Quick Start (Termux Setup)

1. Repository Clone Cheyandi:
   ```bash
   git clone https://github.com/pspktech/whatsapp-ai-bot.git
   cd whatsapp-ai-bot
   ```
2. Dependencies Install Cheyandi:
   ```bash
   npm install
   ```
3. System Tools Install Cheyandi (Termux):
   ```bash
   pkg install yt-dlp ffmpeg
   ```
4. Environment Variables Setup:
   ```bash
   cp .env.example .env
   ```
   Taruvata .env file ni open chesi, mee keys (Groq API, Spotify, WhatsApp number, etc.) add cheyandi.
5. Bot Run Cheyandi:
   ```bash
   npm start
   ```
   Modati sari run chesinappudu terminal lo QR code vastundi. Phone lo WhatsApp → Linked Devices → Link a Device ki velli scan cheyandi.

· SPOTIFY_REFRESH_TOKEN=xxxxxxxxxxxx

Keys Ela Techukovali:
